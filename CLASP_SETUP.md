# Швидке оновлення коду через clasp (замість ручного копіювання файлів)

Це налаштувати треба **один раз**. Після цього кожне майбутнє оновлення —
одна команда в терміналі, замість копіювання кожного файлу вручну.

## Крок 1. Встановити clasp (один раз)

У терміналі (Termial.app на Mac):

```
npm install -g @google/clasp
```

Якщо команда `npm` не знайдена — спочатку встановіть Node.js з https://nodejs.org (кнопка LTS), і повторіть команду вище.

## Крок 2. Увійти в Google-акаунт через clasp (один раз)

```
clasp login
```

Відкриється браузер — увійдіть тим самим акаунтом Google, де ваш проєкт Apps Script.

## Крок 3. Дізнатись ID вашого проєкту (один раз)

1. Відкрийте ваш проєкт на script.google.com
2. Ліворуч — "Налаштування проєкту" (значок ⚙️)
3. Скопіюйте "Ідентифікатор скрипту" (Script ID) — довгий рядок літер/цифр

## Крок 4. Прописати ID у файл .clasp.json (один раз)

⚠️ **Важливо:** файл `.clasp.json` починається з крапки — це "прихований файл",
і macOS Finder **не показує** такі файли після розпакування архіву за замовчуванням.
Тому в архіві є ще й копія під звичайною назвою — `clasp-config.json`.

Найпростіше — через термінал, перебуваючи в папці з файлами проєкту:

```
mv clasp-config.json .clasp.json
```

Потім відкрийте `.clasp.json` (у терміналі: `nano .clasp.json` або в будь-якому
текстовому редакторі, вказавши повний шлях) і замініть
`ВСТАВТЕ_СЮДИ_ID_ВАШОГО_ПРОЄКТУ` на скопійований ID.

*(Альтернатива без терміналу: у Finder натисніть Cmd+Shift+. (крапка) — це
покаже приховані файли, і зможете відредагувати `.clasp.json` напряму.)*

## Крок 5. Увімкнути Apps Script API (один раз)

Перейдіть на https://script.google.com/home/usersettings і увімкніть
перемикач "Google Apps Script API".

---

## Далі — щоразу, коли я даю новий архів:

1. Розпакуйте архів у ту саму папку (заміняючи старі файли)
2. У терміналі, перебуваючи в цій папці, виконайте:

```
clasp push
```

Це завантажить **усі** файли одразу — без ручного копіювання. Займає секунди.

3. Розгортання (щоб зміни потрапили на живий сайт) можна теж зробити командою:

```
clasp deploy
```

Або, як і раніше, вручну через Deploy → Manage deployments → New version —
обидва варіанти працюють, `clasp deploy` просто швидше.

---

**Підсумок:** одноразове налаштування (кроки 1-5) забирає хвилин 10-15,
але після цього кожне майбутнє оновлення — це `clasp push` замість
копіювання 30+ файлів вручну.
